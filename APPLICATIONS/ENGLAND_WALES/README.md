# LSE-REEF index for England and Wales

This folder contains the official 2020 LSE-REEF Index download used by the
combined browser atlas.

- Source: https://cep.lse.ac.uk/pubs/download/occasional/op061_data.zip
- Downloaded: 27 September 2026
- Source archive SHA-256:
  `27427BBE4F0BE03C05D57F82BFB8CCF4F406924CFE7C2582850073135FDA024B`
- Coverage: 34,753 lower-layer super output areas, 2010–2020

`Data` contains the published wide-format CSV. `Shapefile` contains the matching
LSOA boundaries with the index columns attached. See
`README-LSE-REEF-INDEX-2020.txt` for the authors' original documentation and
terms of use.

When using these data, cite Ahlfeldt, Carozzi and Makovsky (2023), *A
micro-geographic house price index for England and Wales*.
