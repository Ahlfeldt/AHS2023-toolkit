# Citation requirement

Use of the index files in this folder is conditional on citing Ahlfeldt, Heblich
and Seidel (2023), *Micro-geographic property price and rent indices*, Regional
Science and Urban Economics 98.
https://doi.org/10.1016/j.regsciurbeco.2022.103836

Users should additionally cite Ahlfeldt, Carozzi and Makovsky (2023), *A
micro-geographic house price index for England and Wales*.
